# Fernwise: finance dashboard template (shadcn/ui + Tailwind)

A personal finance dashboard for the web: net worth and monthly KPIs, six-month cash flow, spending by category against budgets, recent transactions, accounts and upcoming bills. Built with React, shadcn/ui, Tailwind CSS v4, Recharts and Lucide icons. The full design system is in [DESIGN.md](DESIGN.md) and the theme tokens in `src/index.css`.

```bash
npx degit ummydev/ui-templates/shadcn/finance-dashboard my-finance-dashboard
cd my-finance-dashboard && npm install && npm run dev
```

Open `/` to see the dashboard (1440×1000). It shares the Fernwise design system with the [finance app](../finance).

Ask your agent to make it yours:

```text
This is the Fernwise finance dashboard template. Rename it to [your product], replace the sample data in src/data.ts with [your features], and keep the design system in DESIGN.md.
```

All names, people, amounts and copy are made up for the template.
