# Fernwise: personal finance app template (shadcn/ui + Tailwind)

Six mobile screens for a personal finance and budgeting app: home with balance and weekly spending, activity, insights with budgets, savings goals and a challenge, send money, and card controls. Built with React, shadcn/ui, Tailwind CSS v4, Recharts and Lucide icons. The full design system is in [DESIGN.md](DESIGN.md) and the theme tokens in `src/index.css`.

```bash
npx degit ummydev/ui-templates/shadcn/finance my-finance-app
cd my-finance-app && npm install && npm run dev
```

Open `/` to see every screen, or `/?screen=home` (home, activity, insights, goals, send, card) for one.

Ask your agent to make it yours:

```text
This is the Fernwise finance app template. Rename it to [your product], replace the sample data in src/data.ts with [your features], and keep the design system in DESIGN.md.
```

All names, people, amounts and copy are made up for the template.
